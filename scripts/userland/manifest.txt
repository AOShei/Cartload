# Where each file of Cartload's console system comes from (scripts/userland/assemble.sh).
#
#   <rd|pkg> <path> <source>
#
# rd is the boot ramdisk, pkg the package. Sources:
#   out:<path>      scripts/userland/build.sh's own builds (target/userland/out)
#   br:<path>       built by Buildroot (its target tree)
#   hakchi:<path>   the hakchi fork's checkout (scripts and data, text)
#   dl:<name>       a file sources.txt pins, downloaded by scripts/userland/build.sh
#   uboot:<path>    scripts/uboot/build.sh's output (target/uboot/out)
#   kernel:<what>   scripts/kernel/build.sh's output: zImage, modules (the package's
#                   lib/modules/<release>), ramfs (the ramdisk's modules-ramfs)
#   boot.img        made by assemble.sh from kernel:zImage and the ramdisk
#   version         made by assemble.sh: var/version with this kernel's release
#   shipped         kept from hakchi v1.0.4-126 as it is (listed in the report as not yet ours)
#   drop            not carried over (reason in the comment)
#
# Every program (ELF) of the shipped ramdisk and package needs a line here; assemble.sh stops
# on one without. Symbolic links and directories follow the shipped layout; a line for a path
# that is a link there replaces the link.
